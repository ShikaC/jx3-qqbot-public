# 常见问题

## 1. 这套机器人花哪些钱？

| 项目 | 计费方式 | 预估 |
|---|---|---|
| JX3API 令牌 | 按「次数」充值，不按时间 | 例如 5000 次 / 约 ¥50 一档 |
| JX3API 事件版 | 独立服务，不在普通套餐里 | 本项目不使用 |
| LLM API | 按 token 计费 | 20 多人小群通常每月几元级 |
| 主机 | 用自己的 Windows 电脑 | 边际成本 0 |

没有必须付费的其它依赖：AstrBot、插件、NapCat 都免费。

## 2. 次数会过期吗？

JX3API 的充值页按「次数」售卖，令牌查询接口会显示「已用 / 剩余次数」；
时间型令牌才会显示到期时间。购买后建议截图留存。

## 3. 怎么买 JX3API？

1. 打开 <https://www.jx3api.com/>。
2. 右上角点 `token` 登录 / 注册。
3. 进「充值」页选档位并付款。
4. 回面板复制令牌，填进机器人（重新运行 `install.cmd` 即可）。

档位选择建议 5000 次：官网写「购买的是 LV.2 令牌，可调用 LV.2 及以下全部数据接口」，
本项目用到的查询都在这个范围内。价格与档位可能调整，以官网页面为准。

## 4. 非官方 QQ 机器人有封号风险吗？

有风险，且没有官方公布的封号率。NapCat 仓库里出现过账号被踢下线、
群消息功能被临时限制、新号反复风控等案例。

降低风险的做法（不保证 100% 安全）：

- 用有正常使用记录、已绑手机的老号，不要用刚注册的小号。
- 让机器人长期稳定在线，出口 IP 与 QQ 登录 IP 尽量一致（本机部署天然满足）。
- 控制频率：不要秒回、不要群发、不要主动加好友。
- 只在自己小群里用，不做大规模拉群。
- 不要把机器人当成唯一联系方式。

这是「可能损失一个小号」的风险，能接受再上。

## 5. 有现成的开源项目吗？

有，本项目就是它们的组合：

| 项目 | 作用 |
|---|---|
| [AstrBotDevs/AstrBot](https://github.com/AstrBotDevs/AstrBot) | 机器人框架，自带 WebUI、LLM 接入、插件系统 |
| [qsc20001102/astrbot_plugin_jx3](https://github.com/qsc20001102/astrbot_plugin_jx3) | 剑网 3 数据查询插件（v3.5.5） |
| [NapNeko/NapCatQQ](https://github.com/NapNeko/NapCatQQ) | QQ 协议端（非官方），实现 OneBot v11 |

本仓库额外做了：Windows 一键安装脚本、默认群友人格、AstrBot 整合配置，
以及上游插件中的逐条功能开关和可折叠分类管理页。

## 6. 推栏 ticket 是什么？为什么不用？

推栏 ticket 是剑网 3 官方 APP 的登录凭据，JX3API 用它查询**个人账号维度**的数据
（战绩、名剑排行、阵眼、技能、奇穴等）。它需要用户提供自己的登录凭据，而且会失效。

本项目默认不做需要 ticket 的功能。例外：`资历 区服 角色` 走的是不要求 ticket 的接口，
所以可以直接使用。

## 7. 奇遇实时播报为什么没有？

JX3API 把秒级实时推送划进「事件版」，官网写明不在普通购买范围内，也没有自助入口。
本项目默认只保留历史查询（`奇遇` / `未出` / `统计` / `攻略`），不会主动推送实时事件。
需要时在群内发送 `事件推送 开启` 并订阅对应事件；付费事件还需先在插件配置里填入
事件推送令牌。

如果以后想做「奇遇播报」，可以改用轮询接口，但会按间隔持续消耗令牌次数：

| 轮询间隔 | 单区服每天调用 | 5000 次能用多久 |
|---|---|---|
| 5 分钟 | 288 | 约 17 天 |
| 10 分钟 | 144 | 约 34 天 |
| 15 分钟 | 96 | 约 52 天 |
| 30 分钟 | 48 | 约 104 天 |

对小群来说这笔持续开销不划算，所以默认不做。

## 8. 机器人会对群里每句话都回吗？

是否回话由 AstrBot 的唤醒规则决定，剑三插件没有在源码里增加聊天过滤逻辑。

- 剑三指令（如 `角色 梦江南 某某`）由插件解析。
- AI 聊天是否触发，请在 AstrBot 后台调整唤醒前缀、会话开关或 @ 规则。

如果没有填写 LLM API Key，本项目默认关闭对话能力，只保留剑三查询。

## 9. 我可以改机器人的人格吗？

可以。默认人格在 `deploy/config/default-persona.txt`，改完重新运行 `install.cmd`
即可写入；也可以直接在 AstrBot 管理后台里修改。

## 10. 这个项目可以商用 / 二次分发吗？

本仓库整体按 AGPL-3.0 发布；剑三插件基于 AGPL-3.0 的上游项目修改，
再分发时需要保留许可证、原作者信息与版权声明，并按 AGPL 提供对应源码。
NapCat 使用 Limited Redistribution License，**不要修改**，只能按原样运行。

## 11. 怎么更新剑三插件？

可以使用 AstrBot 的「更新插件」，但它可能升级到尚未验证的上游版本。需要恢复
固定版本时，运行 `deploy/windows-native/install-plugin.ps1`；已有的
`features` 功能开关配置会保留。也可以重新运行 `install.cmd`，同时写入 JX3API
Token 等默认配置。
